Things to try

  • Unlock with the password above: Copy, then Ctrl+V in the field, or type it.
  • Search, or filter to favourites and codes.
  • Open Email or Code host: the one-time code counts down.
  • Show and copy a password, then edit an item and save it.
  • Add a login and make a password with the generator.
  • Lock it again from the top of the list.

The demo vault is made in this page when it opens and holds fake data only. Nothing is sent anywhere and nothing is kept: reload to start over. What the browser can't do here: the system clipboard is the page's own, and there is no file to bring in.
